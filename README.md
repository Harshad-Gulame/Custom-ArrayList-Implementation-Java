# Custom ArrayList Implementation in Java

This project demonstrates a custom implementation of the ArrayList data structure in Java without using Java's built-in ArrayList class.

## 🚀 Project Objective

The main goal of this project is to understand how dynamic arrays work internally and how ArrayList manages resizing, indexing, and element manipulation.

## 🛠 Features Implemented

- Dynamic resizing of array
- Add elements
- Remove elements
- Get element by index
- Set element by index
- IndexOf method
- Size tracking
- toString method implementation

## 🧠 Concepts Covered

- Object-Oriented Programming (OOP)
- Dynamic Memory Allocation
- Arrays
- Data Structures fundamentals
- Time Complexity basics

## 📌 Why This Project?

This project helped me understand how Java’s built-in ArrayList works internally and strengthened my Data Structures fundamentals.
